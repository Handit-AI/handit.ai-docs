# Advanced Guides

> **Take your autonomous engineer to the next level.** These guides help you maximize the capabilities of your autonomous engineer for AI evaluation and optimization.

## AI Evaluation

Your autonomous engineer needs to understand what "good" looks like to detect when things go wrong. AI evaluation provides the quality standards and automated assessment that powers intelligent issue detection.

**What you'll learn:**
- Set up automated quality assessment using LLM-as-Judge technology
- Create custom evaluators for your specific use cases
- Monitor quality metrics and detect performance degradation
- Integrate evaluation with your autonomous engineer workflow

<Cards.Card title="AI Evaluation Guide" href="/guides/evaluation/overview" arrow />

## Autonomous AI Fixes

Once your autonomous engineer detects issues, it needs to fix them automatically. This guide covers how your engineer generates improvements, tests them, and ships them via GitHub pull requests.

**What you'll learn:**
- Connect GitHub integration for automated PR creation
- Understand how autonomous fixes work and get validated
- Set up A/B testing to prove fix effectiveness
- Monitor the complete fix lifecycle from detection to deployment

<Cards.Card title="Autonomous AI Fixes Guide" href="/guides/optimization/overview" arrow />
