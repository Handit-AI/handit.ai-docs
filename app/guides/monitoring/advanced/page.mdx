# Advanced Setup

> **Node-by-node monitoring for specialized use cases.** This guide covers the advanced approach for granular control over individual operations.

<Callout type="warning">
  **Recommended**: Use [Manual Setup](/autonomous-engineer/guide/manual_setup) with the `@tracing` decorator for most use cases. This advanced approach is only for very specific scenarios.
</Callout>

## When to use advanced setup

**Use this only when:**
- You need to monitor individual LLM calls separately from agent workflows
- You're building custom monitoring tools that require granular operation data
- You have complex agent architectures that don't fit the standard pattern
- You need backward compatibility with existing implementations

**For most use cases**, the simplified agent-level monitoring is recommended.

## What you're doing

You're manually tracking each operation in your agent workflow, including individual LLM calls and tool executions.

```python filename="advanced_setup.py"
from handit import HanditTracker

tracker = HanditTracker()
tracker.config(api_key="your-api-key")

async def process_customer_request(user_message: str):
    # Start monitoring session
    tracing_response = tracker.start_tracing(agent_name="customer_service_agent")
    execution_id = tracing_response.get("executionId")
    
    try:
        # Monitor each operation manually
        intent = await classify_intent(user_message)
        tracker.track_node(
            input=user_message,
            output=intent,
            node_name="intent_classification",
            agent_name="customer_service_agent",
            node_type="tool",
            execution_id=execution_id
        )
        
        response = await generate_response(intent)
        tracker.track_node(
            input=intent,
            output=response,
            node_name="response_generation",
            agent_name="customer_service_agent", 
            node_type="llm",
            execution_id=execution_id
        )
        
        return response
        
    finally:
        # End monitoring session
        tracker.end_tracing(execution_id=execution_id, agent_name="customer_service_agent")
```

```javascript filename="advanced_setup.js"
import { startTracing, trackNode, endTracing } from '@handit.ai/node';

const processCustomerRequest = async (userMessage) => {
    // Start monitoring session
    const tracingResponse = await startTracing({ agentName: 'customer_service_agent' });
    const executionId = tracingResponse.executionId;
    
    try {
        // Monitor each operation manually
        const intent = await classifyIntent(userMessage);
        await trackNode({
            input: userMessage,
            output: intent,
            nodeName: 'intent_classification',
            agentName: 'customer_service_agent',
            nodeType: 'tool',
            executionId
        });
        
        const response = await generateResponse(intent);
        await trackNode({
            input: intent,
            output: response,
            nodeName: 'response_generation',
            agentName: 'customer_service_agent',
            nodeType: 'llm',
            executionId
        });
        
        return response;
        
    } finally {
        // End monitoring session
        await endTracing({ executionId, agentName: 'customer_service_agent' });
    }
};
```

<Callout type="warning">
  **Why this is complex**: You must manually track every operation, manage execution IDs, and handle session lifecycle. The `@tracing` decorator does all this automatically.
</Callout>

## Migration to simplified approach

**Before (Advanced):**
```python
# Complex manual tracking
tracing_response = tracker.start_tracing(agent_name="agent")
execution_id = tracing_response.get("executionId")
try:
    result = await my_function()
    tracker.track_node(input=input_data, output=result, ...)
finally:
    tracker.end_tracing(execution_id=execution_id, agent_name="agent")
```

**After (Simplified):**
```python
# Simple decorator
@tracing(agent="agent")
async def my_agent_function():
    result = await my_function()
    return result
```

**Benefits:**
- 90% less code
- Automatic operation capture
- No manual session management
