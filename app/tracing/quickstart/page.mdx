# AI Agent Tracing Quickstart

> **Give your autonomous engineer eyes to see your AI.** Choose between automatic setup with the CLI or manual integration with decorators.

<Callout type="info">
  **Two setup options**: CLI automatically generates code, or manual setup where you add decorators. For complete autonomous engineer setup, use our [Main Quickstart](/quickstart).
</Callout>

## Option 1: CLI Setup (Recommended)

Automatic code generation for your agent functions:

```bash filename="terminal"
npm install -g @handit.ai/cli
handit-cli setup
```

The CLI detects your agent functions and generates tracing code automatically. No manual coding required.

<Callout type="success">
  **Setup complete!** Your autonomous engineer is now monitoring your AI automatically.
</Callout>

## Option 2: Manual Setup

Add tracing decorators to your main agent functions yourself:

### Install and configure

<Tabs items={["Python", "JavaScript"]} defaultIndex="0">
<Tabs.Tab>
```bash
pip install handit-ai
```

```python filename="config.py"
from handit_ai import configure
configure(HANDIT_API_KEY="your-api-key")
```
</Tabs.Tab>
<Tabs.Tab>
```bash
npm install @handit.ai/handit-ai
```

```javascript filename="config.js"
import { configure } from '@handit.ai/handit-ai';
configure({ HANDIT_API_KEY: "your-api-key" });
```
</Tabs.Tab>
</Tabs>

### Add tracing to your agent

**✅ DO trace (agent entry points):**

<Tabs items={["Python", "JavaScript"]} defaultIndex="0">
<Tabs.Tab>
```python filename="agent.py"
from handit_ai import tracing

# Trace your main agent function
@tracing(agent="customer-service")
async def process_customer_request(message):
    intent = await classify_intent(message)     # Captured automatically
    context = await search_knowledge(intent)    # Captured automatically
    response = await generate_response(context) # Captured automatically
    return response

# For FastAPI - route decorator goes ABOVE tracing
@app.post("/chat")
@tracing(agent="chat-api")
async def chat_endpoint(request):
    return await process_customer_request(request.message)
```
</Tabs.Tab>
<Tabs.Tab>
```javascript filename="agent.js"
import { startTracing, endTracing } from '@handit.ai/handit-ai';

// Trace your main agent function
const processCustomerRequest = async (message) => {
  startTracing({ agent: "customer-service" });
  try {
    const intent = await classifyIntent(message);     // Captured automatically
    const context = await searchKnowledge(intent);    // Captured automatically
    const response = await generateResponse(context);  // Captured automatically
        return response;
  } finally {
    endTracing();
  }
};
```
</Tabs.Tab>
</Tabs>

**❌ DON'T trace helper functions:**
```python
# These get captured automatically - don't add @tracing here
async def classify_intent(message):
async def search_knowledge(query):
async def generate_response(context):
```

<Callout type="warning">
  **Key point**: Only trace your main agent functions that handle user requests. Everything inside gets captured automatically.
</Callout>
