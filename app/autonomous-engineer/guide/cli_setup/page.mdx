# CLI Setup

> **Automatic code generation for your AI agents.** The CLI analyzes your code and generates monitoring code automatically.

<Callout type="info">
  **Prerequisites**: Node.js and a Handit.ai account. The CLI handles everything else.
</Callout>

## What you're doing

The CLI will:
1. **Connect** your Handit.ai account
2. **Find** your agent functions in your code
3. **Generate** monitoring code automatically
4. **Configure** your API key

## Step 1: Install the CLI

```bash
npm install -g @handit.ai/cli
```

## Step 2: Run Setup

```bash
handit-cli setup
```

Follow the prompts to connect your account and configure your project.

## What the CLI generates

The CLI creates monitoring code for your main agent functions:

<Tabs items={["Python", "JavaScript"]} defaultIndex="0">
<Tabs.Tab>
```python filename="agent.py"
# Auto-generated by handit-cli setup
from handit_ai import configure, tracing
import os

# Auto-generated configuration
configure(HANDIT_API_KEY=os.getenv("HANDIT_API_KEY"))

# Auto-generated decorator for your main agent function
@tracing(agent="customer-service")
async def process_customer_request(message):
    # Your existing code here - unchanged
    intent = await classify_intent(message)
    response = await generate_response(intent)
    return response
```
</Tabs.Tab>
<Tabs.Tab>
```javascript filename="agent.js"
// Auto-generated by handit-cli setup
import { configure, startTracing, endTracing } from '@handit.ai/handit-ai';

// Auto-generated configuration
configure({ HANDIT_API_KEY: process.env.HANDIT_API_KEY });

// Auto-generated monitoring for your main agent function
const processCustomerRequest = async (message) => {
  startTracing({ agent: "customer-service" });
  try {
    // Your existing code here - unchanged
    const intent = await classifyIntent(message);
    const response = await generateResponse(intent);
    return response;
  } finally {
    endTracing();
  }
};
```
</Tabs.Tab>
</Tabs>

**Key point**: The CLI only adds monitoring to your main agent functions, not to helper functions. Everything inside gets captured automatically.

## Verify it's working

1. **Run your agent** with a test request
2. **Check [dashboard.handit.ai](https://dashboard.handit.ai)** - you should see traces appearing
3. **Look for your agent name** in the dashboard

<Callout type="success">
  **Done!** Your autonomous engineer can now see your AI and will start monitoring for issues.
</Callout>

## Managing your setup

**Update configuration:**
```bash
handit-cli setup
```

**When to re-run:**
- After adding new agent functions
- If monitoring stops working
- To update to latest approach
