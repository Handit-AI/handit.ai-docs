# Setting up your autonomous engineer

> **Give your autonomous engineer eyes to see your AI.** Choose between automatic setup with the CLI or manual integration with decorators.

<Callout type="info">
  **Two setup options**: CLI automatically generates code, or manual setup where you add decorators. For complete autonomous engineer setup, use our [Main Quickstart](/quickstart).
</Callout>

## Option 1: CLI Setup (Recommended)

**What you're doing:** The CLI will automatically find your agent functions and generate monitoring code.

```bash
npm install -g @handit.ai/cli
handit-cli setup
```

Follow the prompts to connect your account and configure your project.

<Callout type="success">
  **Setup complete!** Your autonomous engineer is now monitoring your AI automatically.
</Callout>

## Option 2: Manual Setup

**What you're doing:** You'll add monitoring code to your main agent functions yourself.

### Step 2: Add monitoring to your agent

**Where to put it:** On your main agent function that handles user requests.

<Tabs items={["Python", "JavaScript"]} defaultIndex="0">
<Tabs.Tab>
```python filename="agent.py"
# ADD THESE IMPORTS at the top of your file
from handit_ai import configure, tracing
import os

# ADD THIS CONFIGURATION at the top of your file
configure(HANDIT_API_KEY=os.getenv("HANDIT_API_KEY"))

# ADD THIS DECORATOR to your main agent function
@tracing(agent="customer-service")
async def process_customer_request(message):
    # Your existing code here - unchanged
    intent = await classify_intent(message)     # Captured automatically
    context = await search_knowledge(intent)    # Captured automatically
    response = await generate_response(context) # Captured automatically
    return response

# For FastAPI - ADD DECORATOR to your route
@app.post("/chat")
@tracing(agent="chat-api")  # ADD THIS LINE
async def chat_endpoint(request):
    return await process_customer_request(request.message)
```
</Tabs.Tab>
<Tabs.Tab>
```javascript filename="agent.js"
// ADD THESE IMPORTS at the top of your file
import { configure, startTracing, endTracing } from '@handit.ai/handit-ai';

// ADD THIS CONFIGURATION at the top of your file
configure({ HANDIT_API_KEY: process.env.HANDIT_API_KEY });

// ADD startTracing() and endTracing() to your main agent function
const processCustomerRequest = async (message) => {
  startTracing({ agent: "customer-service" });  // ADD THIS LINE
  try {
    // Your existing code here - unchanged
    const intent = await classifyIntent(message);     // Captured automatically
    const context = await searchKnowledge(intent);    // Captured automatically
    const response = await generateResponse(context);  // Captured automatically
    return response;
  } finally {
    endTracing();  // ADD THIS LINE
  }
};
```
</Tabs.Tab>
</Tabs>

**What you're adding:**

**Python:** Add imports, config, and `@tracing(agent="your-agent-name")` decorator **above** your main agent function.

**JavaScript:** Add imports, config, `startTracing({ agent: "your-agent-name" })` at the **beginning** of your function and `endTracing()` in a **finally block** at the end.

**What NOT to do:**
```python
# ❌ Don't add decorators to helper functions - these get captured automatically
async def classify_intent(message):
async def search_knowledge(query):
async def generate_response(context):
```

<Callout type="warning">
  **Key point**: Only monitor your main agent functions that handle user requests. Everything inside gets captured automatically.
</Callout>

## Verify it's working

1. **Run your agent** with a test request
2. **Check [dashboard.handit.ai](https://dashboard.handit.ai)** - you should see traces appearing
3. **Look for your agent name** in the dashboard
